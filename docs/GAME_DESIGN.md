# Flooria — Game Design Foundation

## Positioning
Flooria is a gentle, atmospheric, endlessly rising tower of varied puzzles and
small games, not a medical brain-training application.

## Core loop
1. See the current tower floor.
2. Enter a new mini-game challenge; consecutive floors should differ.
3. Complete the objective, optionally earning mastery stars.
4. Unlock the next floor; revisit favorite games in the Game Library.

## Art direction
Soft Dreamlike 2.5D, near-white backgrounds, lavender and mint accents,
procedural geometry, short transitions, calm sounds, responsive mobile controls.

## Library
All / Recent / Favorites tabs; searching, filtering, saved games and
per-game levels are planned. Favorites and recent history are already local.

## First playable slice
- 2048 with swipe and keyboard controls.
- Number Trail with three sequence questions.
- Tower selection and locally persisted floor.
- Home, Tower, Games, My Mind screens.

## Scope boundaries
This is an early playable foundation, not the full feature set:
- Brain radar and 3D brain are not implemented.
- Arcade games, story, achievements and substantial difficulty calibration follow later.
- Reaching arbitrary high floors is currently a prototype schedule, not the
  eventual varied content director.
