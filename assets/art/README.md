# Flooria artwork

Place the optimized WebP files from `flooria_game_assets_ready.zip` here,
without changing their names:

- whimsical_floating_castle_island.webp (hero tower)
- ornate_garden_quest_panel.webp (mission plaque)
- ornate_golden_crown_button_with_foliage.webp (Play CTA)
- glowing_puzzle_crown_pedestal.webp (Games shortcut)
- royal_blue_castle_tower_icon.webp (Tower shortcut)
- enchanted_brain_altar_emblem.webp (My Mind shortcut)
- fantasy_garden_puzzle_game_ui.webp (2048)
- royal_fantasy_victory_panel.webp (victory modal)

The Flutter UI already uses the asset paths with safe painted fallbacks, so
the game stays playable while artwork is uploaded. For web performance,
prefer the provided optimized WebP files rather than source PNG files.
